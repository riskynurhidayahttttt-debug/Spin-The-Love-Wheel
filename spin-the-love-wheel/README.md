# Spin The Love Wheel

Website mini-game roda kejutan romantis untuk demo katalog Pipo Studio.

## Fitur
- Roda keberuntungan dengan animasi putaran.
- Hasil dipilih secara acak dari opsi yang tersedia.
- Tambah dan hapus pilihan hadiah/tantangan/pesan (2–10 opsi).
- Reset ke pilihan contoh.
- Efek suara tick dan nada kemenangan menggunakan Web Audio API.
- Tombol sound on/off.
- Responsif untuk desktop dan mobile.

## Menjalankan
1. Buka folder ini di VS Code.
2. Jalankan `index.html` dengan Live Server, atau buka langsung di browser.
3. Tambahkan opsi custom di panel **Wheel options**, lalu tekan **SPIN THE WHEEL**.

## Catatan
Demo ini berjalan sepenuhnya di browser. Opsi yang diubah tidak tersimpan setelah halaman dimuat ulang. Belum ada dashboard admin, penyimpanan database, atau link unik per pelanggan. Font Google memerlukan koneksi internet.


## Tema visual
Project ini memakai nuansa dongeng musim gugur: kuning madu, emas, oranye daun, dan cokelat hangat. Terinspirasi suasana hutan musim gugur yang ceria dan cozy; aset karakter berlisensi tidak disertakan.
